# Golden Crown crown reference

`iiaf-emblem.svg` is the unmodified [IIAF Seal by Pajam](https://commons.wikimedia.org/wiki/File:IIAF_Seal.svg), licensed under [Creative Commons Attribution-ShareAlike 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/). It is used for the **Return to F-4** button and Tehran scenario card, with original colors and transparency preserved. The earlier user-supplied `iiaf-emblem.png` is retained as a reference.

`team-crest.svg` is the unmodified [Golden Crown emblem by Pajam](https://commons.wikimedia.org/wiki/File:Golden_Crown.svg), licensed under [Creative Commons Attribution-ShareAlike 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/). The **Fly Golden Crown** button uses this SVG with original colors and transparency. `team-crest.png` is the earlier user-supplied reference.

`pahlavi-crown.png` is the unmodified crown detail supplied by the user from the Golden Crown model reference material. The source image is preserved; the model shader discards its white background at render time. The artwork is third-party reference material, not original project artwork; no open license has been established.
